# 🎁 Sibling Vault (Family Bond Vault)

> **A personalized, interactive digital memory capsule & celebration platform for siblings.**

---

## 🌟 Overview

**Sibling Vault** allows any brother or sister to create an emotional, gamified, and beautiful digital memory experience for their sibling.

- 📸 **Single Memory Photo**: Adaptive zero-crop photo frame with ambient backdrop & wax-sealed secret notes.
- 💌 **Festive Sibling Wish**: Heartfelt personalized greetings + curated gift recommendations (Amazon, Flipkart, Nykaa, FNP, Blinkit, etc.).
- 🎰 **The Punishment Wheel**: Physics-based interactive spin wheel for dares and chores.
- 🎟️ **Coupons & Awards**: Redeemable vouchers with celebratory confetti and printable funny award certificates.
- 🌶️ **Roast & Fun Zone**: Sibling roast wall, WhatsApp dare challenge, favor contracts, and crime fine calculator.
- 🧾 **Emotional Reply Receipt**: Phase 2 recipient reaction portal with WhatsApp sharing & PDF receipts.
- 🌐 **Zero-Latency Bilingual Engine**: Real-time switching between English 🇬🇧 and Hinglish 🇮🇳.

---

## 🚀 Quick Start (Local Development)

### 1. Backend Setup (Node.js + Express + MongoDB)
```bash
cd backend
npm install
npm run dev
# Server runs at http://localhost:5000
```

### 2. Frontend Setup (React 18 + Vite)
```bash
cd frontend
npm install
npm run dev
# App runs at http://localhost:5173
```
